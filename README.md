# Etnotherapeutics Research Showcase

A GitHub Pages portfolio page for the research project:

**Etnotherapeutic: Nurse Communication Intervention Based on Silih Asah and Silih Asih to Enhance Resiliency in Lung Cancer Patients**

Published in *Jurnal Komunikasi*, Vol. 18, No. 1, July 2026, pp. 51–70.  
DOI: https://doi.org/10.24912/v18i1.35540

## About this repository

This repository contains a portfolio-oriented summary of the published research, including its background, conceptual framework, methodology, statistical analysis approach, key findings, and my individual contribution.

The study was conducted collaboratively by a multidisciplinary team. My contribution focused on the statistical analysis aspect.

## GitHub Pages setup

1. Create a repository named `pkm-etnotherapeutics` (or another project-specific name).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Notes before publishing

- Add the partial notebook only after reviewing it and removing patient-level or identifiable information.
- Do not upload raw patient records, identifiable data, or confidential hospital materials.
- Keep the findings consistent with the published article. The 3.16× and 2.92× values are reported interpretations from the article; they are not absolute probabilities or percentage-point increases.
- Update the notebook link in `index.html` only after the notebook has been added and checked.
